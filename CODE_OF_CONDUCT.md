# Code of conduct

Treat contributors and users with respect. Discuss ideas and behavior rather than attacking people. Welcome questions, give actionable feedback, and respect different levels of experience.

Harassment, discrimination, threats, unwanted sexual attention, deliberate disclosure of private information, and disruptive behavior are unacceptable. Never post another person's contact information, credentials, or application records without permission.

Report concerns to a repository maintainer through an available private channel. If no channel is listed, request a private contact in an issue without identifying the affected person or publishing sensitive details. Maintainers may remove content, limit participation, or close discussions to protect the community, and should explain decisions to affected participants when appropriate.

This guidance applies to repository discussions, issues, pull requests, and project community spaces. Maintainers and contributors are expected to follow it equally.
