# First-access screenshots

Captured from the running local application on October 11, 2026:

- [Desktop first access](screenshots/first-access-desktop.png).
- [Mobile first access](screenshots/first-access-mobile.png), using a 390 CSS-pixel viewport.

Both images show the initial platform-administrator signup form on an empty installation. Name, email, password, and confirmation fields are empty. No real account, customer records, secrets, or preloaded tournament data appear in the images. No administrator was created for this screenshot review.

The narrow viewport was checked for horizontal overflow. These captures document initial setup layout; they do not establish physical iPhone/Android compatibility or comprehensive accessibility acceptance. Those checks remain in the [release checklist](release-checklist.md).
